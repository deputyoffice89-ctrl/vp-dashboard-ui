# شاشة المتابعة الخاصة بمكتب نائب الرئيس

هذا المستودع يحتوي **ملفات الواجهة فقط**، المعدة للنشر على GitHub Pages. البيانات الفعلية (مواضيع مرسال والبريد) موجودة في المستودع **الخاص** `deputyoffice89-ctrl/vp-office-dashboard`، ولا تُنسخ هنا.

## تشغيل الموقع
من **Settings → Pages** اختر **Deploy from a branch** ثم `main` و `/(root)` ثم **Save**. بعد اكتمال نشر GitHub Pages سيظهر رابط الموقع في صفحة Pages.

## الدخول والحفظ
- لعرض المواضيع أو تعديلها يستخدم الموقع GitHub API مع رمز وصول Fine-grained **تكتبه أنت داخل الشاشة**؛ لا يوجد أي رمز مخزّن في HTML أو JavaScript.
- يجب أن يكون الرمز مخولاً للمستودع الخاص `vp-office-dashboard` بصلاحية **Issues: Read and write**. قد تستخدمه أنت وزميلك على جهازين مختلفين، لكن مشاركة الرمز تُضعف الأمان وتعني أن جميع التعديلات تُنسب لحساب مالكه. الأفضل رمز مستقل لكل موظف، ويمكنكم استخدام كلمة مرور مشتركة فقط إذا توفرت لاحقاً خدمة مصادقة آمنة.
- لا تضفوا الرمز إلى GitHub Issues أو ملفات المشروع أو رسائل عامة؛ احفظوه في مدير كلمات مرور.
- الإحصائيات والبيانات تأتي من مستودع المواضيع الخاص بعد تسجيل الدخول، ويمكن تعديلها أو إضافة تحديثات من الواجهة نفسها.
- مهلة الموضوع 14 **يوماً تقويمياً** من تاريخ وصوله إذا كان مسجلاً. عدم وجود تاريخ وصول يعني عدم احتساب التأخير.

## الخصوصية
**هذا مستودع عام للواجهة فقط؛ لا يحتوي على ملف الإكسل أو سجل المواضيع أو رموز الوصول.** لا تغيّر خصوصية مستودع البيانات الخاص.
